# Mini ATM

A simple ATM simulation built with Python.

## Features

* User login with username and password
* Hidden password input using `getpass`
* Account balance display
* Deposit money
* Withdraw money
* Input validation for invalid amounts
* Password changing
* Logout
* Repeating ATM menu while logged in

## What I Practiced

* Lists and nested lists
* `for` loops
* `while` loops
* `if`, `elif`, and `else`
* User input with `input()`
* Error handling with `try` and `except`
* `getpass` for hidden password input
* Variables and Boolean values
* Updating data inside nested lists
* Program flow and login sessions

## How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python mini_atm_v2.py
```
